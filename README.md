# Vamos de Van Tur

Site institucional responsivo em português, com logo vetorial, serviços e formulário que prepara uma mensagem para envio pelo Instagram.

## Visualizar

Abra `index.html` no navegador ou execute `python3 -m http.server 8080` na pasta do projeto.

## Contato

O formulário não envia nem armazena dados: prepara uma mensagem para copiar e enviar para @vamosdevantur.

## Imagens

A foto de van é ilustrativa (Mercedes-Benz Sprinter, apresentada pela Merbag) e não representa a frota da empresa. Substitua pelas fotos autorizadas da frota antes de uso comercial definitivo.
